# Skills

The starter catalog stores skills in SQLite with a name, short description, body, requested permission list, status, and pin flag. The router sees descriptions; the inspector can reveal the selected skill body. Five concise starter instructions are seeded for review, debugging, research, incident triage, and release notes.

The full SKILL.md parser, progressive file loading, trust hashes, scripts sandbox, 150+ seed library, duplicate checks, activation lifecycle, and user skill import are not yet implemented. Dashboard create buttons direct users to the lifecycle workflow; that workflow currently supports review state only.
